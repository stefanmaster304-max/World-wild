Welcome to Stefan's Project Repository
Welcome to Stefan's public project repository! This repository contains my ongoing development work, including Android applications, text-to-speech (TTS) engines, and audio games for Windows.
About My Projects
My work focuses on accessible software and offline audio games. When it comes to game development, I prefer working on offline projects rather than online games developed with the assistance of AI coding tools.
The reason is simple: large-scale refactoring and architectural changes in online games can introduce complicated problems involving client-server communication, connection stability, latency, and synchronization. These issues often require extensive testing and troubleshooting, which can make development unnecessarily time-consuming and frustrating.
Offline games are generally easier to maintain, test, and refactor because they do not depend on the same network infrastructure or client-server interactions. For this reason, I prefer to focus my development efforts on offline experiences where I can work more efficiently and maintain better control over the codebase.
This repository is public, and everyone is welcome to explore its contents. New projects, improvements, and updates will be published as development progresses. Check back regularly to stay informed.
