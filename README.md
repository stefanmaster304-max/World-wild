# Stefan's Project Repository

Este repositório contém atualmente apenas o código-fonte do Smart Voice para Android. O projeto foi reduzido a uma base sem engines: não há SDKs de fala, bibliotecas nativas, pacotes de vozes, APKs compilados nem serviço TTS registrado.

Consulte [SmartVoice/README.md](SmartVoice/README.md) para detalhes e instruções de compilação.
