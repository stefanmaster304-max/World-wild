# stefan_progects

Site oficial de Stefan para apresentar projetos próprios e de parceiros, compartilhar informações sobre o desenvolvimento e publicar links para downloads. O site é em português e tem foco em acessibilidade, inclusão, jogos e tecnologia.

## Publicação

O conteúdo do site está em `docs/`. Para publicar pelo GitHub Pages, selecione a branch `main` e a pasta `/docs` em **Settings → Pages → Build and deployment**.

Os arquivos de projetos e jogos não devem ser armazenados na pasta publicada do site. Quando houver projetos prontos para divulgação, as páginas de cada projeto poderão apontar para os respectivos downloads em GitHub Releases.
