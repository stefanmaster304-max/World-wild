# Projetos de jogos

Esta pasta reúne projetos de jogos que não fazem parte do site publicado pelo GitHub Pages. No momento, não há jogos neste repositório.

Quando um novo projeto de jogo for iniciado, esta pasta poderá conter seu código-fonte e, quando disponível, sua versão compilada para download.

A pasta `games/` fica fora da origem do site, que é `docs/`.
